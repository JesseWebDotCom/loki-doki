## Access

The Admin panel is available to users with the `admin` role. Open it from the settings icon in the navigation.

## Sections

| Tab | What it manages |
|---|---|
| Features | Enable/disable features; trigger installs |
| Users | Create and manage user accounts |
| Companions | Create and configure AI companions |
| LoRAs | Add and manage image generation style add-ons |
| Privacy | Set the adult content PIN and countdown duration |
| Archives | Add and manage offline library (ZIM) archives |
| Maps | Add and manage offline map regions |
| Links | Add and manage global bookmarks |
| Troubleshooting | Chat and router benchmarks |

## Users

Create user accounts with a username and initial PIN. Assign the `admin` role to give another user full access. Regular users can only see the features granted to them.

## Model Installation

The Features tab shows the install status of all AI models and components. If something is missing, tap **Install** to download it. Progress streams inline. No need to leave the page.

## Troubleshooting

The Troubleshooting tab provides:
- **Chat benchmark**: tests the full chat pipeline across 9 scenarios and reports latency per step
- **Router benchmark**: tests tool routing accuracy across 30 natural language variations
