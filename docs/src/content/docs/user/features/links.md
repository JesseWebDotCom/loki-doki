A launcher for your own home network and the sites you choose. Personal bookmarks are private to you. Nothing here is shared with, or tracked by, anyone outside your home.

## Overview

The Links page is a bookmark launcher for your home network services, frequently visited sites, and personal shortcuts.

## Opening a Link

Tap any bookmark card to open it. Links open in a full-screen viewer inside the app, so you stay in context.

## Adding Personal Bookmarks

1. Open the Links page
2. Tap **Add Bookmark** (bottom of the My Links section)
3. Enter a title and URL
4. Optionally add an icon URL and category

Your personal bookmarks are only visible to you.

## Global Bookmarks

Global bookmarks are set by your admin and appear for all users. They typically include shared home network services, media servers, smart home dashboards, router admin, etc.

## The Viewer

When you open a link, it loads in a full-screen frame with a toolbar:
- **Back / Forward**: navigate within the site
- **Reload**: refresh the page
- **Open in new tab**: break out to a real browser tab
- **Close**: return to the Links page
