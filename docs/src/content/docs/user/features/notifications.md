Loki Doki can reach you outside the app itself: a browser push notification, a Telegram message, or an email, depending on what you set up and what kind of alert it is.

## What Sends a Notification

Things like a price-drop alert, a watched page changing, a finished download, an app install request, or a camera event all generate a notification. In **Settings → Notifications**, you decide how each kind reaches you: off, right away, or bundled into a daily digest, per channel.

## Turning On Each Channel

- **Push**: works out of the box, no setup beyond allowing browser notifications when prompted.
- **Telegram**: an admin has to connect a Telegram bot for the household first (**Admin → Notifications**). Once that's done, you link your own Telegram in **Settings → Notifications**: generate a short one-time code, send it to the bot as a message, and you're linked.
- **Email**: also needs an admin to configure outgoing mail first (**Admin → Notifications**).

## Chat With Your Companion Over Telegram

Once you've linked Telegram, it isn't just for alerts. Message the bot directly and you're talking to your own companion, with the same memory and conversation history as chatting in the app. Send it a plain link and it saves as a bookmark, the same as pasting one into Bookmarks.

## Screen Pods

If your household has a screen device (a Pod), relevant alerts also pop up briefly on the screen itself, like a download finishing or someone at the door.

## A Note on the Internet

Push, Telegram, and email all require an internet connection to deliver.
