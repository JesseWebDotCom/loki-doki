A dedicated space for anything your companion writes that's bigger than a chat bubble, live, and editable.

## Overview

When you ask for something substantial, a script, a document, a small web page, your companion can open it in **Canvas** instead of dumping it into the chat as a wall of text. It streams in as it's written, and it stays open in a side pane so you can keep reading the conversation at the same time.

## Editing together

Canvas isn't read-only. Keep typing changes directly into it yourself, or just tell your companion what to change ("make the intro shorter," "fix the bug in this function") and it edits the same document in place rather than starting over.

## Kinds of content

- **Code**: a script or snippet in any language, with syntax highlighting
- **Documents**: formatted text, notes, a letter, an outline
- **HTML**: a small, self-contained web page you can preview live

## Revisiting your canvases

Tap **Canvas** in the sidebar any time to see everything your companion has written for you, pin the ones you want to keep handy, and reopen any past canvas to keep editing it.

## Exporting

Export any canvas to PDF to save or share outside the app.

## Canvas vs. Coding

Canvas is for a single file you want to read, tweak, and keep. If you're asking for a whole project with multiple files that needs to run, that's a job for [Coding](../coding/) instead.
