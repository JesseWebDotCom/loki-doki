Skills let you shape how your companion behaves without editing its core personality. A skill is a small, reusable set of instructions: give it a name, a one-line description, and the instructions themselves, and your companion picks it up when it's relevant to the conversation.

## Creating a Skill

Open **Skills** and add a new one with a form, or write it directly as markdown (a short YAML header plus your instructions in plain text, for more control). Turn on **Always active** if you want a skill to apply to every message rather than only when your companion judges it relevant.

## Your Skills and Shared Skills

Skills you create are yours alone. An admin can also publish shared "family" skills that every household member gets: you can toggle a shared skill on or off for your own chats, but only its owner can edit it, so everyone's experience stays under the admin's control where it matters.

## Turning Skills On and Off

Every skill, yours or shared, has a toggle. Turn off anything you don't want influencing your companion right now, without deleting it. Deleting a skill removes it for good.

## A Note on the Internet

Creating and managing skills works entirely offline; whether a skill actually changes a response still depends on your companion's normal chat connection.
