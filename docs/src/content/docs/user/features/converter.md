The File Converter turns a file from one format into another, right on your server. Nothing is uploaded to a third-party converter site, and it works completely offline.

## Converting a File

Drag a file in, or browse for one, and Loki Doki shows a live preview alongside the valid output formats for that kind of file (an image only ever converts to another image format, and so on):

- **Images**: PNG, JPG, WEBP, BMP, TIFF, GIF, and SVG, plus AVIF and HEIC/HEIF if your server has the optional image library installed.
- **Audio**: MP3, WAV, FLAC, AAC, OGG, OPUS, M4A, AIFF, and WMA.
- **Video**: MP4, MKV, MOV, WEBM, AVI, M4V, WMV, and FLV.

Pick your target format, adjust the quality slider if it's a lossy format, and start the conversion.

## Progress and History

Conversions show live progress: queued, converting, then done, with a button to cancel a running job. A **Recent** list keeps your past conversions so you can download a finished file again or retry one that failed, with a status badge for each.

## A Note on the Internet

Everything happens locally on your server, so the File Converter works completely offline.
