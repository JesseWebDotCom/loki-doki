An AI coding agent, running in a real terminal, in a workspace that belongs only to you.

## Overview

Coding gives you a genuine terminal, powered by [Claude Code](https://claude.com/product/claude-code), running right in the app. Describe what you want to build or fix in plain English and it writes the code, runs commands, and iterates, the same way it would for a professional developer, just aimed at your own project.

## Your own sandbox

Every person's coding session runs in its own private workspace, kept separate from your host computer and from every other family member's projects. Nothing you build here can reach outside that workspace.

## Split panes

Split your terminal horizontally or vertically to run more than one thing at once, a server in one pane and a build in another, for example. Drag the divider to resize, and close a pane when you're done with it.

## It keeps running

Close the tab, reload the page, or come back tomorrow: your session and everything running inside it are still there. Only closing your terminal panes yourself stops anything.

## Ask your companion instead

Don't want to sit and watch it work? Ask your companion in chat to kick off a coding task ("build me a script that renames these files") and it runs in the background. You'll get a notification when it's done, with a summary of what happened, and you can open Coding any time to see the full result.

## Canvas vs. Coding

If you just want one file, a script, a document, a small web page, that's a better fit for [Canvas](../canvas/), which is faster to open and lets you keep editing right there in chat.
