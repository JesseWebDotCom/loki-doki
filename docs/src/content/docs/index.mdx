  <Card title="Chat" icon="comment">

  </Card>
  <Card title="Image Generation" icon="pencil">

  </Card>
  <Card title="Voice" icon="phone">
    Hands-free wakeword detection, Whisper STT, and Kokoro-82M TTS, all running locally with no cloud dependency.
  </Card>
  <Card title="Companions" icon="star">
    A fully customizable, animated AI buddy with its own name, personality, voice, and look. It breathes, reacts, and lip-syncs as it talks, and it's yours, not built to hook you.
  </Card>
  <Card title="Offline Library" icon="open-book">

  </Card>

  </Card>
  <Card title="Home Inventory" icon="list-format">
    AI-powered device tracker. Photo → VLM identify → web lookup. Service logs, warranty alerts, and manual PDF cache.
  </Card>
